# Experiment No. 4: Introduction to Tableau and Installation

## Aim
To study Tableau and install Tableau Public for creating interactive visualizations.

## Algorithm
1. Open a web browser and visit the official Tableau Public website.
2. Download Tableau Public for the operating system.
3. Run the installer and follow the installation wizard.
4. Launch Tableau Public.
5. Verify that the Tableau Home screen appears.
6. Explore Connect, Open, Worksheet, Dashboard, Story, Data Pane, Marks Card and Filters.

## Result
Tableau Public was installed successfully and the basic Tableau workspace was explored.
