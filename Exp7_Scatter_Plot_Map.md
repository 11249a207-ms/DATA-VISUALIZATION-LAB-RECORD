# Experiment No. 7: Creating Scatter Plot Maps in Tableau

## Aim
To connect geographic sales data and create a scatter plot map in Tableau.

## Algorithm
1. Open Tableau Public.
2. Connect to `sales_map_data.csv`.
3. Check that Latitude and Longitude are numeric fields.
4. Drag Longitude to Columns and Latitude to Rows.
5. Add Category or Region to Color.
6. Add Sales to Size.
7. Review the scatter plot map and save the workbook.

## Result
A scatter plot map was created using the geographic coordinates in the dataset.
